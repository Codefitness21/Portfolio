Fitness Motivator App

I attended a Learn to Code workshop in 2018 through the Austin Coding Academy in Austin, which was my first introduction to a structured javascript lesson. The instructor guided the class from initializing the project in github to developing and deploying our very first app! The GOAL of the project was to design and build a quote generator. I was employed as a fitness professional during this time so a fitness themed app seemed appropriate. As a SOLUTION, I used several motivational quotes that hold significant meaning in my life, to help motivate and support my clients with their fitness aspirations.

This was a very simple build using HTML, CSS, and JavaScript. The Get Hype title immediately grabs ones attention along with a sub-title that further speaks to the idea of the app. An image representing fitness as well as a royal blue background color draws visual appeal. The background was also selected to complement the blue color in the picture. Within the app, a green button with a “pressed” effect is positioned below the image, which generates several quotes when clicked. View the project below and GET HYPED AND MOTIVATED!!!!
