Digital Seat Media Website

I am an employee with the sports company, Digital Seat Media. It is a mobile web-based platform that provides interactive fan engagement at live events by allowing fans to simply scan a QR-code-enabled tag located directly on the armrest of their seat.

Digital Seat Media Mobile

Goal: Redesign the current Digital Seat Media website into a more user friendly, visually appealing, and structure layout that also demonstrates a compatible design for tablets and mobile devices. Identify and resolve site pain points to drive improvements.

Problem: The website is poorly organized, and could use significant improvement for better usability. The user experience is hindered by an ineffective site layout.

Solution: Beginning with the landing page, create an easily navigable layout that sets the tone for the other pages in the site that provides an effective user experience and increases clarity and ease at which the user locates information.

Prior to coding the website, several low and high fidelity wireframe iterations were designed in an XD document. The website consists of minimal information, creating a user-friendly experience that's inviting and easy to navigate. CSS flexbox was used to structure the majority of the website for purposes of regulating the spacing and dimensions, allowing for proper image and text alignment. Want to see for yourself?!
